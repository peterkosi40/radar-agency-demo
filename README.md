# Radar Studio — Demo Website

A responsive, static digital-agency website concept created for a portfolio demonstration.

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## What's included
- Responsive layouts for phones, tablets and desktops
- Mobile navigation
- Filterable concept-project gallery
- Accessible form labels and keyboard focus states
- Contact form that prepares an email in the visitor's mail app
- Original generated architectural hero image in `the project root directory (same folder as index.html)`
- No JavaScript frameworks, paid libraries, backend or API keys

## Important demo notes
- Radar Studio and the projects shown are demonstration concepts, not claimed client work.
- The contact form opens a mail application addressed to `peterkosi40@gmail.com`. Replace that placeholder with a real address you control before public launch. The form does not store or transmit submissions itself.
- The page uses Google Fonts when internet access is available, with local system-font fallbacks.
- The project is static and can be previewed without a server.
